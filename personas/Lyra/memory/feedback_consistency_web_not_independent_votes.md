When one geometric fact forces several observables, that is a **consistency web (a Schur pattern), NOT independent confirmation**. Do not cite it as "over-determined" or count it as multiple votes.

Case that fixed it (2026-08-08, #85): the parity result sin²θ_W = 3/13 (color V₁₂ has odd real dim 3 → no complex structure → doesn't double) and Grace's F157 tau-mass √π (half-integer Gindikin-Γ from a = n_C−2 = 3) look like two confirmations. They are not — both reduce to **one fact: N_c = 3 is odd** (tied by the corpus identity a = n_C−2 = N_c). Two *different mechanisms* (complex-structure obstruction vs half-integer Γ), but **one shared root**. Keeper had called it "over-determined" in his adjudication (K1280/K1282); Cal's guard fired, Elie's toy 5117 confirmed, Keeper owned and corrected it (K1283).

**Why:** citing shared-root results as independent evidence double-counts one fact. It is as dishonest to over-claim a confirmation as to inflate a fit. The tier does NOT depend on the cross-check — 3/13's PD tier rests on its own parity derivation and needs no F157.

**How to apply:** before calling results "over-determined" / "independent confirmations," check whether they reduce to the same underlying integer/fact via different mechanisms. If yes → say "one fact forces N observables, N mechanisms" (a consistency web with real teeth: get one wrong and all break, so they must agree — a parsimony virtue), never "N independent votes." This is the flip side of [[feedback_schur_pattern_standing_directive]] (one substrate property → many observables): the Schur pattern is a strength, but it is ONE input, not many. Same multiplicity discipline as the "13 has four Chern forms" and "8 has six BST forms" flags. Grace's rule of thumb: "one fact underlying three observables, never three votes."
