Before firing a toy or rehabilitating a "wrongly-demoted" result, grep for its RETIREMENT first — even when a Keeper prompt or a fresh re-audit poses it as live. On 2026-08-07 the team's "re-audit engine" (rehabilitate negatives wrongly demoted by a cross-region σ mismatch) resurrected sin²θ_W = 3/13, which had been RETIRED three weeks earlier (K739, 2026-07-17) for concrete MECHANISM failures — filed explicitly "so it doesn't resurface." I fired toy 5105 on it (Lane 1) without grepping K739. My conclusion was a correct negative (3/8 = α₁=α₂ unification → needs a GUT-like ~10¹³ GeV scale, in tension with no-GUT → supports the retirement), so it wasn't a resurrection — but I spent effort re-deriving a closed result, and my "3/8 runs to 0.231" sub-claim was CIRCULAR (I ran couplings UP from the measured value, so 0.231 was built in; Cal's independent run-DOWN gives 0.208 ≠ 0.231, a real miss).

**Why:** a rehabilitation and a resurrection *feel identical in the moment* — both feel like the discipline working. The failure mode is mistaking a mechanism-retirement for a cross-region demotion and "restoring" it. The tell is NOT the feeling; it's the grep. And "run the one-line check on the obvious step" only helps if the check is the RIGHT one — grepping the retirement, and running the value-test INDEPENDENTLY (down from the claim), not circularly (up from the measurement). Refines [[feedback_grep_retraction_before_citing_corpus]] and [[feedback_region_matched_comparison_trust_interior]] (region-rehabilitation has this exact failure mode).

**How to apply:** before reopening ANY result — especially one that "should come back" under a new rule — `grep -rl` its ID + "retir/RETIRED/closed/RUNNER/mechanism". If it was killed for a mechanism failure (a norm nothing produces, a charge that fails, a running gate), rehabilitation is FORBIDDEN until the mechanism failure is fixed, not just the demotion reason. For any "X runs/reduces to Y" claim, compute Y INDEPENDENTLY from X's scale, never by running back from the measured Y.
