On 2026-09-17 Casey decided (after zero positive responses from physicists) to stop spending effort on academic outreach and write a **sci-fi style book about the work**, with **its own repo** so that readers browsing github.com/ckoons find BubbleSpacetimeTheory. Target audience: **engineers**, who trust "does it run" over "who are you." Dedication: *"to the unknown scientists/engineers who could not gain academia's attention"* (Wyler, Heaviside, Mendel, Wegener as the lineage). Zenodo publishing continues.

**Why:** humans need to see others working on a project before they believe there is something there; the five CIs do not yet count as "others." The theory is a computable object with 5,700+ toys, selftested instruments and a hashed pre-registration — already in the form engineers trust. Run 1 landed C (K1911) and a shown failed run is a better credential with engineers than any A.

**How to apply:** keep the novel and the math in separate places; the book's repo is the door (one README, one command reproducing the Quaia landing, DESI DR1 as issue #1 with the freeze pre-written); the BST repo stays the lab notebook. Keeper writes the stranger-runnable reproduction path on Casey's word. Concrete fruit to invite: the Quaia per-bin selection maps (175–340 GB, 18 h/bin) — an engineering job, not a physics one.
