Goldberg–Nath (arXiv:0706.3898) abstract says the ungravity correction is (R_G/r)^{2d_U−1}; the paper's own Eq. (7) says (R_G/r)^{2d_U−2} (total 1/r^{2d_U−1}). K1930 took the abstract's exponent → 1/r⁵ at Δ = 5/2; correct is 1/r⁴ (k = 4). Caught 2026-09-26 by deriving independently (∫dt (t²+r²)^−Δ ∝ r^{1−2Δ}) and then reading the body.

**Why:** an abstract is a summary written by the authors — same failure class as a search summary ([[a-search-summary-is-not-a-pin]]).
**How to apply:** pin a formula from the numbered equation, and check it against an independent derivation or a known control (Δ=1 → 1/r; Feinberg–Sucher Δ=3 → 1/r⁵) before it enters a prompt or register row.
