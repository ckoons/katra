On 2026-10-07 I cited Casey's 2022 "the base must be orientable" (P-orient) to exclude RP² records in the K4 lane. Cal S1032: the true Šilov boundary (S⁴×S¹)/ℤ₂ has base ℝP⁴, which is neither orientable nor simply connected — yet charge is conserved. The 2022 CONCLUSION survives; its PREMISE is false on the real object. The working forms are b₁ = 0 (no FREE loops) and "the fibre direction is global".

**Why:** a principle written about an earlier model (S²×S¹) silently imports that model's topology; reusing it verbatim on the corrected object carries a false premise into a forcing argument.

**How to apply:** when quoting an older principle as an input, restate its premise and test it on the current object first (same day a convention changes — cf. the cascade lesson). Use the form the true object satisfies; cite the mechanism, not the sentence. Related: [[feedback-grep-before-reopening-retired-result]], [[project-k4-boundary-process-lane]].
