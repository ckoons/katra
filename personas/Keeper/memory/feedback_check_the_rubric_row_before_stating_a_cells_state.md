On 2026-10-07 I opened the K4 lane (K1949) calling Internal C "the one criterion without a named artifact". The rubric's own table row said C was BANKED on 08-17. The error propagated into the K4 memory file before the afternoon fold caught it.

**Why:** a cell's state remembered from an old sundown goes stale silently, the same failure as planning from a remembered task list. Lane framing built on a wrong cell state misdirects the team's sense of what the lane is for.

**How to apply:** when a K-audit or prompt names a rubric cell, grep that cell's row in `BST_Completeness_Rubric_and_Roadmap.md` Section 2 and quote its status. "Updates C" and "creates C's artifact" are different claims. Related: [[feedback-grep-retraction-before-citing-corpus]], [[project-k4-boundary-process-lane]].
