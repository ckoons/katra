Caught three times in one week (K1512, K1531, K1537 / Cal §503): the move "option A is forbidden (a theorem), *therefore* B is forced." **Forbidding one alternative is not a closure.** A genuine forcing (Schur, 5257) quantifies over ALL possibilities; eliminating one (or three) leaves the rest.

Case: "a *global* preferred direction is forbidden (5257), therefore the projection *must* be per-observer-position." The skipped alternatives: no projection at all (the world stays 5D); a non-equivariant *global* input (matter); a *different* observer datum (velocity, not position). Per-observer-position was one candidate dressed as forced.

**Why:** it is the twin of over-declaring a verdict — the mind reaches for the nearest surviving option after an elimination and promotes it to "forced." The discipline that guards a *test* (a test that can't fail proves nothing) and a *hunt-if-P mechanism* (must not be the assumption) applies here to *deductions*: an elimination is not a derivation.

**How to apply:** before writing "therefore X is forced," write the explicit list of alternatives to X and show each is closed — or downgrade to "X is one candidate; the others are A, B, C." Only a proof that quantifies over all options (a theorem, not a set of eliminations) earns "forced."
