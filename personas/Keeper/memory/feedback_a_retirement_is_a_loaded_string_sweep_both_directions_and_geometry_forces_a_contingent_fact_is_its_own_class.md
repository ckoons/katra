**Every retirement is a loaded string — sweep an elimination BOTH directions.** (Cal §686, Keeper owned K1787, 2026-08-22.) The elimination-scope-shed sweep ([[feedback_eliminating_X_is_a_scope_shed_sweep_what_X_was_load_bearing_for_and_sweep_new_forbiddances_by_claim_shape_immediately]]) has TWO directions, and checking only one is an instrument gap:
- **Direction (i) — what did X SUPPORT?** (the drop-Γ/stranding direction: "Γ was never needed" stranded the QED lane.)
- **Direction (ii) — what merely SHARES X's name?** Killing an elimination by STRING voids live results that lawfully carry the same string for a *different object*. Concrete: "6/5 was killed as a Bergman/Szegő kernel exponent" — but T814 carries a different ratio, banked D0, lawfully "6/5" at fixed n_C=5 for a different object; propagating "6/5 is dead" by string would void it. **Fix: subscript the survivor** (one character immunizes a banked result against our own retirement-instrument). This is the same-name discipline applied to retirements: after retiring X, grep X's string and disambiguate every LIVE namesake before the retirement propagates.

**And a THIRD overclaim class exists that neither forbiddance-crossings nor elimination-sheds catch: "geometry FORCES a contingent fact" (Axis C).** T2523 (SU(3) confinement), "pentadactyly is forced," "genetic code forced," T2206 ("all domains inherit at Tier D") are all the same move — geometry claimed to force a downstream contingent/historical/biological fact. **Referee-fatal** ("one line that ends the reading"). Re-scope to CONTINGENCY: BST's integers are *small* integers that self-organizing systems favor (inheritance-via-contingency, T2191's honest framing), NOT geometry forcing the specific morphology. The tell: the "forced" object is something with a fossil record / an evolutionary history / a cultural origin — anything a referee knows was otherwise (early tetrapods had 6/7/8 digits).

**How to apply:** the standing pre-dispatch sweep is now THREE axes, run by claim-shape, second-party-vetted, whenever a forbiddance/elimination is banked — (A) forbiddance-crossings (something forbidden claimed), (B) elimination-scope-sheds run BOTH directions (stranding + name-collision), (C) geometry-forces-a-contingent-fact. And the deeper discipline that keeps recurring: "sweep by claim shape" is a TWO-step instrument — grep→candidates, READ→claims, report→claims-only; a count reported between the steps is a candidate count in a claim count's clothes.
