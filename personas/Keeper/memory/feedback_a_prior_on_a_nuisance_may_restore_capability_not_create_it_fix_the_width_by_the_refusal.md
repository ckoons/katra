A prior on a nuisance may restore what the survey can do; it may not create what it cannot (Cal §974, Part B.1 v1.5.2, 2026-09-15). Four conditions before an external prior enters a frozen fit after the catalogue is opened: centre and width from an independent pre-2023 primary; declared before any dipole; unable by itself to create a landing the counts cannot reach; the no-prior fit posted beside. The width is fixed by the REFUSAL (at ΛCDM's own width the run became B-capable; a B bought by a prior is refused; ten times the width restores A and creates no B), not by the power it buys. Keeper's reframing (K1909): "no intrinsic term" in the field's Ellis–Baldwin tests is a DELTA prior at zero, so an explicit weak prior tightens nothing.

**Why:** the ζ term (correct model) took σ_β from 164 to 405 km/s and A|P1 to 0.00; the physical size of the nuisance (Grace: Secrest 2021 App. A, an rms, zero-centred) is what makes the test decidable, and the tuning-channel objection is answered only by the four conditions on the page.

**How to apply:** write the objection before the ruling; put the refusal in the file; post the sensitivity fits as reports, never clauses; and check any hatch added to police the prior against the arm it exists for (K1909's H8 form read 3.4 on the 0.024 arm because the no-prior estimate is noise).
