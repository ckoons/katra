**A label that is SUFFICIENT where it was formed can be INSUFFICIENT one bundle over.** This is a third
species, distinct from (a) two objects sharing a name and (b) an overloaded symbol.

**The exhibit (D_IV⁵, 2026-08-23, R73).** At λ = 0 the K-types are V_(d,0) and the SO(5) label **determines**
the polynomial degree — so the corpus could write "K-types carry SO(5) label (d,0)" and lose nothing.
At spinor λ, Δ ⊗ V_(d,0) = V_(d+½,½) ⊕ V_(d−½,½), so **every V_(a,½) with a ≥ 3/2 arrives twice** (from
d = a−½ and d = a+½), separated **only by SO(2) weight**. Drop SO(2) and two distinct K-types collapse into one.
Verified exact on Weyl dimensions d = 0…6.

**Grace hit the same disease from the other end**: the word "scalar" did two jobs in one sentence — trivial
in the *color* factor (which color-singlet forces) and trivial as a *K-type* (which it does not). A lepton is
a color singlet **and** a spinor.

**Why it evades the existing guards.** Subscripting an overloaded symbol doesn't help — there is only one
object here. Grepping for a name collision finds nothing. **The habit is genuinely safe where it was learned**,
which is why it survives review: every use in the origin setting is correct.

**How to apply:** when a result moves to a new bundle / rank / representation, **ask what the label was
implicitly determining in the old setting** and check whether it still determines it. A label that silently
carried a second coordinate is a candidate. Related: [[feedback_subscript_the_overloaded_symbol_int_vs_function_of_n]],
[[feedback_an_instrument_built_from_N_instances_covers_only_those_N_classes_stress_test_off_origin]],
[[feedback_when_the_reason_is_wrong_do_not_assume_the_number_is_wrong_too]] (Grace kept the genus-p numbers
while retiring their justification).

**Corollary banked the same round (Keeper):** a **spectral** label (Casimir eigenvalue, SO(2) weight, degree)
has an infinite tower, so it can never index a quantity with exactly rank+1 = 3 values. **A 3-valued
generation index must be a SUPPORT/localization label, not a spectrum.**
