**The principle:** a Yukawa/mass/coupling that RGE-runs has no single "true" value — it depends on scale. So: **predict at μ_geo → run down with the measured 2-loop RGE (Machacek–Vaughn / PyR@TE / REAP; masses from Xing–Zhang–Zhou arXiv:0712.1419) → compare in σ.** No free parameter, no knob.
