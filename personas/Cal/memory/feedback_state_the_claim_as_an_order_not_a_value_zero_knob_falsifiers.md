The thermal-generations lane (2026-08-24) owed a T↦τ map as its first debt. The **order-only lemma** dissolved the debt: leaders of w_j·e^{−τE_j} follow the upper envelope, so they appear in strictly decreasing E-order, and **any monotone τ(T) preserves the sequence**. The map was never owed for order-level claims.

**The payoff was the falsifier**: Shilov-first ⟺ E_Shilov > E_Cartan > E_bulk — one comparison, **zero knobs**. When the exponents came back anti-aligned (0, 9/4, 25/4), the mechanism died at the order level with no parameter, map, or clock choice able to save it. **That is the lemma succeeding, not failing** — it made the death clean and certified (K1828).

**Why:** an ORDER is a position; only a VALUE is a coordinate ([[feedback_quote_the_invariant_not_the_coordinate]]). Order-level claims survive every reparametrization, so they can be tested before any calibration exists.

**How to apply:** when a mechanism owes a map, first ask whether the claim can be stated as an ordering. If yes, the map is not owed, the test comes early, and the verdict is unarguable in either direction.
