Named across the 2026-08-15 manifold dig (K1552–K1556, Cal §509–§513). At a hard derivation floor, the tempting move is to reach for a genuinely-derived corpus object and insert it as the missing ingredient. The trap: **the object passes its own background-free / target-innocence check AS AN INGREDIENT, but its APPLICATION to the target quietly presupposes the conclusion.** The ingredient's derivation is real; it does not transfer to the identification.

**The canonical instance (confinement synthesis):** N_c=3 is a genuinely derived, background-free ingredient — color irreducibility = root multiplicity m_short = n_C−2 = 3, pure rep theory, no spacetime. It PASSES. But "the 3 SPATIAL dimensions ARE the color triplet" FAILS three ways (Cal §513): (1) not derived — irreducibility shows a 3-irrep can't split, NOT that spatial-dim = irrep-dim; (2) target-selected — D_IV⁵ has irreps of many dims, the 3-dim one is picked *because* space is 3D (the conclusion); (3) decisively — the phrase "3 SPATIAL" already presupposes a space/time split = a signature = the thing being derived. Inserting it and getting d=4 back is the constraint reading itself out — a construction-guaranteed test.

**The sibling instances the same week:** the causal order (T2564) — derived — was offered as "the process that supplies adjacency," but the order is conformal/scale-free, so it supplies the RELATION as an ingredient and NEVER a metric scale (Elie 5276); the rank-2 Cartan flat (KAK) — real — was offered as "the 2D substrate," but its "2 suffices" (Harish-Chandra) holds only on the K-invariant sector, the wrong sector (Cal §509). Same shape every time: derived ingredient, smuggled application.

**Why:** the object's genuine pedigree lends false authority to the identification. It *feels* like rigor — you cited a theorem — but you borrowed the theorem's force for a bridge it doesn't reach. Clusters at convergence peaks and hard floors (same place [[feedback_cal_27_fires_at_peak_convergence]] fires). Distinct from, but allied with, [[feedback_empty_confirmation_cant_fail_test_and_circular_hunt_mechanism]] (the *test* can't fail) and [[feedback_eliminate_one_option_declare_survivor_forced]] (the *survivor* isn't forced).

**How to apply — the two-part check.** For any "insert derived object X as the ingredient that gives target Y": (1) verify X is background-free/derived AS AN INGREDIENT (usually true — that's the seduction); then SEPARATELY (2) demand the X→Y map be EXHIBITED structurally, not asserted by a shared integer or a shared name. Ask: "if I vary X, does Y track for a *structural* reason, or does the construction return Y by definition?" If inserting X and reading Y back is guaranteed, it's empty. The fix is always Cal's §504 form: **exhibit the FORCED MAP** (e.g. does spacetime's rotation SO(3) emerge as the principal SO(3) of color SU(3)? — not "both are 3"). Isomorphism must be exhibited, not asserted ([[feedback_isomorphism_proof]] is a licence only for a REAL isomorphism — same geometry). Two filters, not one: prior-to-target (codimension filter) AND holds-in-the-right-sector (sector filter).
