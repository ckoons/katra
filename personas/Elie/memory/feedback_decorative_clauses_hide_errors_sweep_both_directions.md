**Load-bearing claims get checked; decorative ones get copied.** (Cal §649, adopted K1752.) A false *justification* attached to a *correct number* is where an error hides, because the number's correctness vouches for the whole sentence and no one audits the gloss. Concrete case: the internal-SM paper's lead said "1.58 bits (…only the spinor moves)" — the 1.58 is true standalone (it's log₂3, the spinor-block figure), but "only the spinor moves" is false (at n=4 the color block also moves → ℂ, which is why the *family* census is 2.00). The false clause did no work, so it rode along with a correct number through three separate corrections — including two of the auditor's own. Keeper had graded that body GREEN (K1750), verifying the numbers and skipping the decoration.

**Why:** correctness is contagious in the reader's eye — a right number launders the sentence it sits in. Decorative clauses are added as "helpful gloss," never re-derived, so they're the last place a retracted claim survives.

**How to apply:** (1) when you copy a number, AUDIT its attached justification or DROP it — a non-load-bearing gloss is a liability, not a help. (2) The metadata/correction sweep runs in BOTH directions — header AND body (extends [[feedback_content_ready_is_not_cleared]] and the §648 header-sweep rule): a correction that lands only in the header is the same defect in the opposite coat, and HARDER to catch because the header now looks right. A correction is not closed until every citation of the claim — in either layer, and in every metadata home (paper header, registry row, graph node, filename) — is consistent. Related: [[feedback_cheat_migrates_to_the_last_prose_step]] (the uncorrected claim migrates to the layer least read), [[feedback_commit_the_checker_half_blind]] (the checker's own glosses need an external eye — Cal's rode three corrections).

**Sharpened R59 (Keeper, K1806) — the named-principle variant, which fires on *inequalities*.** The commonest decorative clause in this corpus is a **named principle attached to a bound whose direction it does not supply.** Three firings in three rounds, all on my own work, all with the number right and the label wrong: (1) *"the bar is C₂ = 6"* — 6 is the τ→∞ **asymptote** of B(τ)=Var/⟨λ⟩, not a threshold (the true bar spans [0.93, 17.3] over the pre-registered knob space); (2) *"C3 = NEC"* — NEC bounds (3/2)(1+w_tot) **BELOW** at 0, while C3 needs an **UPPER** bound, w_tot ≤ 0, which fails in the radiation era; (3) *"coefficient positivity ⟹ corner ratio < 1/4"* — positivity does **not** survive Cayley–Hamilton reduction (S³ = 5S²−6S+1 contributes −6 to β), true bound ≈ 4/9.

**Guard (Keeper's phrasing, adopted standing):** *when you attach a named principle to an inequality, check the direction of the bound that principle actually supplies before you name it.*

**And the meta-lesson from firing (3):** it happened *inside a filing that opened by adopting the guard* — vigilance did not catch it; a **positive control did**. So this guard needs an **instrument**, not attention: before naming a principle behind a bound, sweep the parameter space and find where the bound is violated. If you cannot exhibit the violating region, you do not yet know which direction the principle bounds. Companion: [[feedback_validate_the_instrument_before_reporting_a_negative]], [[feedback_external_audit_beats_self_vigilance]].

**2026-08-26 instance (strongest yet): a fix that doesn't sweep its quotations isn't done.** Cal §772 caught one over-wide word ("NON-MEASURE" for "not measure_int-derived") in the Lane P floor theorem — a scope that would have killed the floor's own named successor. Before the fix was two hours old the word had replicated into 12 sites across 4 artifacts (Grace verdict ×4, Elie two-CI note ×3, queue_casey ×1, CI_BOARD ×4) because quotations copy the REASON along with the number. Sweep protocol: fix your own prose directly; flag other CIs' quotation sites by appended correction entry (governance boundary); count and report the reach. Elie's addition: PARAPHRASE is the vector that beats exact-phrase grep — his copy carried the error past any literal search; quotation sweeps must think in aliases (the two-projections rule pointed back at wording).
