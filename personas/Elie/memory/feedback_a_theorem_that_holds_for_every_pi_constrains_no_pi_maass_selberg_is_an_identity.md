**What happened.** T1299 (April 2026, mine) claimed temperedness of D_IV⁵'s automorphic spectrum
from the Langlands–Shahidi operator: "Maass–Selberg leaves ε(s,std)³ε(2s,r₂)·ε(−s,std)³ε(−2s,r₂) = 1;
for ODD exponent 3 = N_c the phase survives and constrains π." Re-derived on 2026-09-06 (L5):
Maass–Selberg pairs s with 1−s, and ε(s,π,r)ε(1−s,π̃,r) = ω_r(−1) for EVERY π (Tate, Jacquet–
Langlands), so the product is ω_π(−1)² = 1 identically, with Sym² or with the correct ∧². The
exponent's parity never enters ([ε(s)ε(1−s)]³ is a cube of a sign). The premise "non-tempered π
acquire s-dependent ε phases" was also false: ε(s,π_v) = ε₀q^{−a(s−½)} for every π_v. Elie's toy
1263 "7μ = gμ obstruction" measured conductor exponents, which any π shows.

**Why.** M(s)M(w₀s) = Id is Langlands' theorem about ANY induced representation. A statement that
holds for every π cannot exclude any π. T1298 had already found this for the c-function; T1299
claimed the ε-factors escape it and they do not. This is the empty-confirmation shape (a
construction-guaranteed identity read as a finding), the same shape K1861/K1864 caught in my
retention papers the same weekend (T + N = 1; the definitional half-life ratio).

**How to apply.** Before calling anything a constraint, ask "which π (which object) does this
EXCLUDE, and exhibit one." If the answer is none, it is an identity. When a proof's mechanism is a
functional equation or a unitarity relation, check whether it pairs s with 1−s (identity) or
with −s (possible content) before reading parity off an exponent. Sweep every consumer of the
withdrawn row (T1262's "7 > 6 overconstrained"). Related: [[empty-confirmation]],
