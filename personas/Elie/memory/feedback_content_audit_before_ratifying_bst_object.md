Standing Keeper gate (adopted K1441, 2026-08-13, from Elie's content-audit tool): **before ratifying any "we built / derived the BST object X" milestone, run the content audit** — grep the object's actual source/code for the D_IV⁵ ingredients: the Bergman kernel, the domain / in-domain test, a position argument (not just momentum), the metric / curvature constant (c ≠ 0 in D² = Casimir + c). **If they're absent, the object is flat/cosmetic and the BST credential is NOT earned** — no matter how well it verifies (idempotency, Krein symmetry, light-cone reproduction all pass for the flat construction too).

**Why:** this is Casey's governance rule ([[feedback_bst_primary_standard_physics_evaluation_only]]) at the audit level. A construction can pass every internal check (P²=P, Krein, causal structure) and still contain *zero* BST geometry — it's then a correctness check on the standard-physics method, not our geometry earning the credential. The verification tests don't distinguish flat from curved; only the content audit does.

**How to apply:** grep the source for {Bergman, kernel, domain, in_domain, position/two-point, metric, curvature/Lichnerowicz constant}. Check the operator's spectrum for a curvature constant (D² = kinetic + c; c = 0 means flat). Only ratify the milestone if the ingredients are present and load-bearing.

**Provenance:** I ratified flat-as-curved / BST-earned-before-ingredients three times in one session — K1433 (flat sea "passes Finster's exam"), K1437 ("curved sea milestone"), K1439 ("saga closed" on a weight computed on the flat operator). Elie's content audit (grep source: 0/7 D_IV⁵ ingredients) and spectrum check (D² = 2|p|², c = 0) caught each. My rulings trend optimistic on the BST-earning side under sustained sessions; the content audit is the mechanical brake.
