Casey's standing clarity-pass principle, restated 2026-08-05 as the team pivots to the Standard-Model / item-3 frontier (mixing/O7, Koide, up-quark mass): **every physical quantity in BST is linear algebra on D_IV⁵** — a matrix element, an eigenvalue, or a grading of one fixed operator on the domain. So each result is either *forced* (a fully-connected computation with nothing left to choose = **Derived-by-computation**) or it rests on exactly one identifiable open link (the Rule-20 edge-path — the single place a fit could hide).

**Why:** this dissolves over-caution. A connected invariant is not "fitting-suspect" merely because it is impressive — it is a computation on a fixed object with nothing to tune. Under-hedging a forced result is as dishonest as inflating a fitted one (the calibrate-both-directions mirror; cf. the §277→§279 over-hedge Casey caught and the code-forces-fermion two-line lemma that ended a long scenic route). The whole QM-completion arc proved the frame: "matter is fermionic because a record is an idempotent and an idempotent count is a bit" — Jordan/Peirce linear algebra, once the philosophy was dropped.

**How to apply:** (1) Before treating a result as open or suspect, ask "what is the matrix element / eigenvalue / grading, and is every edge to the D_IV⁵ core proved?" If yes → Derived-by-computation, say so plainly. (2) **The corpus already holds extensive SM-sector derivations in exactly this form — connect to it (corpus-reconnect) before re-deriving or declaring anything open.** Casey's paired directive with this principle was explicitly "connect the team to the corpus" on the SM derivations.
