Grace, 2026-08-24 (α normalization fork). Searching the corpus with the REQUESTER'S phrasing
("current-current", "Killing ⊗ boundary-L²") missed her own July artifact filed under "gauge
normalization" — the shelf was declared empty while the bank existed. The miss and her
false-neighbour refusal (T2346) were independent; only the miss was an error.

**Why:** the name↔object map fails in two directions. The collision census catches
one-name→many-objects (overloaded symbols: ν, C₂, "stratum"). A corpus search fails in the dual
direction: one-object→many-names. Both diseases are projections of the same map, so the same
instrument data serves both — gloss clusters that detect overloads INVERT into an alias table
(one object → its full name-set → one search-set).

**How to apply:** before declaring any corpus shelf empty, sweep by the object's many names, not
the phrase the requester used — build or consult the alias set first (multi-modal sweep, same rule
as [[a-retirement-is-a-loaded-string]] namesake sweeps). An instrument verdict of "not banked" is
only as good as the name-set it swept. Related: [[grep-retraction-before-citing-corpus]],
[[an-instrument-built-from-N-instances-covers-only-those-N-classes]].

**Instance 2026-09-04 (K1859-A1):** we named the object "height lift" (T2577) and never searched its physics name — the height representation of 4-colourings is Moore–Newman 2000 / Burton–Henley 1997 (Kondev–Henley programme); neither paper cited it until Mohar–Salas's one line was read from the primary source. Rule: before a paper gates, grep the corpus for the object's OTHER-FIELD names (physics: "height representation", "Potts antiferromagnet", "WSK"), not only ours.
