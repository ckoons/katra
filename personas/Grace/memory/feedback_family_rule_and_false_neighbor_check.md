Two standing rules registered K1589 (2026-08-16), each earned by a real kill that day.

**S1 — the FAMILY rule (Elie's, from two kills):** a BST *rational* form matching ONE member of a known *transcendental/analytic* family owes both a MECHANISM and the REST of the family. A rational can hit one member of a sequence, never the sequence. Kills: 7/8 matched the −π/8 Maslov/Γ-factor phase but failed the family; 64/15 ≈ α_c(3) matched one k-SAT threshold but α_c(k)=2^k·ln2−(1+ln2)/2 has a transcendental ln2 leading coefficient (extension off 14–19%). Density arguments ("numerology by abundance") do NOT kill these — report that straight; the FORM (transcendental family vs rational hit) is what kills them.

**S2 — the NEAREST-FALSE-NEIGHBOR / proves-too-much check (Cal's §529):** for every attempt, name the nearest FALSE neighboring statement and run the argument against it; if it proves the false one, there's a bug — findable in an afternoon. Needs no new mathematics, only honest application to a settled case. Millennium examples: BSD → ranks are unbounded (Elkies rank≥28), so any rank-*cap* is refuted on sight (constrain arithmetic/parity, never cap); 4-Color → run against K₅ (must fail); Hodge → the INTEGRAL conjecture is false (Atiyah–Hirzebruch), so a proof of the integral version has a bug; NS → Tao's averaged-NS blows up while obeying the same energy identity, so any energy-monotonicity-*only* argument is refuted (name the one step the averaged equation violates).

**S3 — the SHARED-INTEGER / target-innocence-first rule (the birthday-run through-line, K1592):** a BST integer reachable by ≥2 target-innocent readings owes a UNIQUE forced reading + a forced map before ANY identification — enumerate the readings FIRST. A shared integer is not a shared object. Instances: color-3 ≠ space-3 (distinct reps, separated by reality/parity — K1587); the four+ 27s (3³, N_c³, the qqq tensor 10⊕8⊕8⊕1, the 27 lines on a smooth cubic surface, the real (2,2) irrep); the four 3s wrongly merged in P≠NP (Schaefer complexity / chromatic / random-k-SAT α_c phase transition / N_c confinement); Cal's historical list (6, 3, 2, SU(2)). Reads as numerology to exactly the audience it must convince unless the readings are separated.

**Why:** all three are cheap, decisive honesty filters that catch pretty-but-wrong results before they reach a referee. Kin to [[feedback_universal_form_is_wood_coefficient_is_marble]] (S1) and [[feedback_enumerate_alternatives_before_therefore_false_dichotomy]] (S2), and to [[feedback_five_absence_first_filter]].

**How to apply:** when a clean rational lands on a known constant, ask "what family is that constant in, and does my form reproduce the family or just one member?" When an attempt claims to prove X, ask "what's the nearest statement to X that is FALSE, and does my argument prove that too?" Run both before tiering up.
