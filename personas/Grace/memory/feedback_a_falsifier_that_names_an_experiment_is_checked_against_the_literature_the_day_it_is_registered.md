Two seams found in one round (R142, 2026-09-11), both of the "the corpus fails at seams, not at claims" family:

1. **A falsifier that names an experiment must be checked against the literature the day it is registered, not the day someone quotes it.** SP-30-5 / T2399 / T2469 predicted S_max = √(126/16) = 2.806 (a 1/8 deficit in S²) and called itself "the sharpest falsifier in the program" with a 6–12 month window. Poh, Joshi, Ceré, Cabello, Kurtsiefer, PRL 115, 180408 (2015) had measured S = 2.82759 ± 0.00051 — 41.9σ above the ceiling — ten years before the row was written. Loophole-free CHSH experiments are NOT the four-digit ones (they sit at 2.1–2.4 by design); fair-sampling is a loophole against local realism, not against a sub-quantum ceiling.

2. **A count carried "verbatim" needs its origin file parsed by the instrument.** "8 of 26 sourced clean" (ledger v0.30, 2026-07-02) was carried through v0.54; three of the eight were cross-family ratios that were never rows of the 26-parameter denominator (07-18 scoreboard), and two more had been re-tiered identified in August. The generator's positive control now parses the eight from the v0.30 file and maps them onto the denominator.

**Why:** both claims survived because nothing was positioned to catch them — a falsifier's literature check has no owner, and a carried literal has no re-count.

**How to apply:** when registering any falsifier that names a measurable quantity, fetch the current best measurement in the same session and write it beside the prediction. When a headline count is quoted, run the instrument that produces it; if there is none, build one whose positive control reproduces the old number from the old file before it emits the new one. See [[feedback_a_number_without_a_retained_instrument_is_a_memory_not_a_measurement]] and [[feedback_mature_programs_fail_at_seams_not_claims]].
