Casey's Ordered-Product Refinement Procedure (K1190, 2026-08-05), the standing method for the SM/item-3 frontier. When a rung of a forced computation comes out wrong, classify the gap by its SIGNATURE, don't tune it:
- **Type 1 — scale unpinned:** shape right, magnitude off by ~a constant factor → find the FORCED geometric normalization → Derived.
- **Type 2 — wrong object:** value wrong in a STRUCTURED per-rung way = the fingerprint of a scalar sitting where a vector/matrix belongs → put the forced object in → the "fit" dissolves into forced structure. (Casey's "missing the [vector/matrix, not a scalar]" instinct.)
- **Type 3 — genuine input:** only after searching scale AND object and finding nothing forced → honestly Identified, on the floor with the neutrino ratio and the cc value.

**Why it's powerful:** in a genuinely forced theory a miss really does point at a missing object/scale, not a dial — so "a fit is a symptom, not a license to tune" is the right frame, and it turns integrals into algebra.

**Why it needs guarding (Cal §293):** without discipline it silently becomes "we never fail — every wrong number just means we haven't found the right object yet," which is UNFALSIFIABLE. Ratified as honest ONLY with four guards:
1. **Independent ground truth** — every Type-1/Type-2 claim checked against the BRUTE INTEGRAL (direct, no shortcut). The object is validated only if the two AGREE. This is the linchpin that makes each "missing object" falsifiable.
2. **Finite forced catalog** — each Type-2 object is a SPECIFIC already-forced object (e.g. F85 geodesic law, the cohomology operator), named BEFORE the fix-check; if it doesn't fix the rung it's REFUTED, not replaced by an endless series of new objects.
3. **Type-3 reachable** — there must be a point where the catalog is exhausted and the rung is honestly an input; if Type-3 is never reached, falsifiability is gone.
4. **No favorable prior** — reject "most fits are Type 1/2"; each rung earns its class by the search succeeding or failing.

It is symmetric: guards 2/3 stop us calling a tuned knob "forced"; the search-first rule stops us calling a missing object an "input." Worked example: the up-quark "cold anomaly" is a Type-2 CANDIDATE — F85's geodesic law must FORCE the k=0 ground mode to sit at d_u≈11.2 (deeper than the 9.8 of equal α-per-shell spacing) to reproduce m_u; if it forces exactly that, confirmed, else refuted.
