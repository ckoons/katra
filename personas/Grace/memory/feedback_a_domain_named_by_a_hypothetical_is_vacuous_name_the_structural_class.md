**What happened:** Keeper's frame proposal (K1836/K1834 A5) named the One-Word Lemma's domain "the
minimal-counterexample class (internally 6-connected)". Cal §818: two classes with one name. Restricted
to minimal counterexamples the lemma is equivalent to 4CT and has no content (vacuous if 4CT, false if
not). Restricted to the structural class (5-connected / internally 6-connected triangulations) it is the
honest strengthened hypothesis — nonempty, testable on real graphs, stronger than 4CT.

**Why:** a hypothesis about the theorem's failure cannot be a domain for a lemma the proof consumes;
the proof only needs the lemma on a structural superclass, and that class is where evidence can live.

**How to apply:** when an induction reduces to a minimal counterexample, derive the counterexample's
structural properties (Birkhoff: 5-connected, δ = 5 — K1834 A5, zero citations) and state every
consumed lemma on the STRUCTURAL class. Name collisions of this kind go in the alias table (Grace row 11).
