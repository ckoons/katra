**A printed consistency check catches what care does not, and it earns its keep precisely when you
are most confident.** (Elie, 2026-08-20, toys 5392–5404.)

Six errors in one day, every one caught the same way — **a printed table disagreeing with the prose
verdict written beneath it.** None was caught by re-reading, and none by being careful.

- **5394**: a missing conjugate in `C T = −T* C` made the anomaly table **verify a claim over an
  EMPTY set** and print CONSISTENT. The non-vacuity count now prints next to the verdict.
- **5395 run 1**: computed the **complex** commutant, which is always dim 2 by Schur — it could not
  distinguish ℝ/ℂ/ℍ **even in principle**, and printed FAILED against its own prose.
- **5395 run 2**: a random search for nilpotents **cannot hit a measure-zero cone**; the separation
  was visible but threshold-dependent. Replaced with the exact trace-form signature.
- **5401**: "colour = ℝ always" — **false at n=4** (SO(2) is abelian, End = ℂ), which killed a
  separator that had been cited for four rounds.
- ★ **5403**: wrote **"n=5 alone satisfies the four conditions"** while the table three lines above
  printed **[5, 11, 13]** — *a false uniqueness claim composed while correcting a false uniqueness
  claim.*

**Why the last one is the whole argument:** vigilance was at its maximum — the entire toy existed to
catch an unswept "unique." Care was not the binding constraint; **the printed table was.**

**How to apply:** print the table, the count, and the control **above** the verdict, and make the
verdict quote them. Never write a summary line that the output does not literally show. Add a
**non-vacuity count** to any "all X have property P" claim — an empty set satisfies everything.
